# This Readme contains detail about the above chat application

## Features
*   Real-Time Messaging: Users can send and receive messages instantly.
*   User Authentication: Secure sign-up and login using encrypted passwords.
*   Responsive Design: Works across desktop and mobile devices.
*   Typing Indicators: See when someone is typing a message.
*   Message Threads: View and reply to specific messages in a thread.
*   Push Notifications: Get notified about new messages when offline.
*   Group Chats: Create and participate in group conversations.
*   Media Sharing: Send images and other file types directly in chat.
*   Profile Management: Customize your user profile with an avatar and personal details.

# Some of the apis used
Stream api & Twilio

# Primary Goals of this ChatApp
* nstant Messaging: Allow users to send and receive messages in real time.
* User Authentication: Secure login and sign-up to ensure safe communication.
* Private & Group Conversations: Enable both one-on-one and group chats.
* Notifications: Alert users about new messages or updates.
* Scalability & Reliability: Provide a stable platform for growing user interactions.
* Media Sharing: Support sending images, videos, and other multimedia files.
* Easy Accessibility: Make communication seamless on both desktop and mobile devices.
